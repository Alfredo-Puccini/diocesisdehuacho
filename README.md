# Portal Web Institucional – Diócesis de Huacho – Perú

Código fuente oficial listo para desplegar en **GitHub Pages** (`diocesisdehuacho.org`).

## Archivos incluidos
- `index.html`: Código completo autocontenido del portal multipágina con las 7 secciones (`Inicio`, `Diócesis`, `Templos`, `Celebraciones`, `Autoridades`, `Obras`, `Contacto`), navegación horizontal en PC y hamburguesa en móvil, y todas las fotografías configuradas con proporción original (<1080px).
- `CNAME`: Archivo de configuración de dominio personalizado (`diocesisdehuacho.org`) para GitHub Pages.

## Instrucciones de publicación en GitHub Pages
1. Entra a tu repositorio en GitHub.
2. Sube los archivos `index.html` y `CNAME` a la rama principal (`main`) reemplazando la versión anterior.
3. En **Settings > Pages**, verifica que la fuente esté en `Deploy from a branch` (`main` / `/ (root)`) y que el dominio personalizado sea `diocesisdehuacho.org`.
